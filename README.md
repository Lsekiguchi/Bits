# 💻 Bits

> Repositório dedicado às soluções desenvolvidas durante maratonas e competições de programação competitiva realizadas ao longo da minha graduação

![C](https://img.shields.io/badge/C-00599C?logo=c&logoColor=white)
![C++](https://img.shields.io/badge/C%2B%2B-00599C?logo=cplusplus\&logoColor=white)
![Status](https://img.shields.io/badge/status-em%20desenvolvimento-success)

Este repositório reúne os problemas resolvidos durante maratonas, competições e sessões de treinamento realizadas no contexto do ITA Bits, iniciativa estudantil voltada ao estudo e à prática de programação competitiva.

## Objetivos

- Desenvolver raciocínio lógico e algorítmico;
- Aprimorar minhas habilidades em C e C++;
- Desenvolver técnicas de otimização de código;
- Melhorar minha capacidade de resolução de problemas sob restrições de tempo;
- Documentar minha evolução em programação competitiva.

## Conteúdo

O repositório está organizado por maratona ou competição. Cada diretório corresponde a uma atividade específica e contém as soluções dos problemas trabalhados.

```
📁 Bits/
    ├── maratona-em-grupo-07-08-2026/
    ├── maratona-em-grupo-29-05-2026/
    ├── ps-bits/
    ├── ...
```

## Tecnologias

- C
- C++

## Conceitos praticados

Entre os principais tópicos explorados nas soluções estão:

- Complexidade de algoritmos;
- Algoritmos de busca;
- Algoritmos de ordenação;
- Recursão;
- Teoria dos grafos;
- Técnicas de otimização

A lista de conteúdos será ampliada conforme novos problemas forem resolvidos e novos conceitos forem estudados.

## Progresso

O repositório está em desenvolvimento e será atualizado conforme a participação em novas maratonas e competições.

## Aviso

Esse repositório possui finalidade exclusivamente educacional.
